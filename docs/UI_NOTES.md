# UI 实现与检查

当前版本 0.8.4 的布局与组件约束见 [Android 设计](design/ANDROID.md)，菜单/权限/返回规则及修复记录见 [流程审查](UI_FLOW_REVIEW.md)。历史版本保留在 Git 中；早期记录见 [0.4.0 历史记录](history/UI_0_4.md)。

主界面使用官方 Material 搜索、底部首页/文件、新建、文件更多菜单；设置使用 AndroidX Preference 和 Material 对话框。连接、公开链接下载和任务详情是职责独立的页面，共用主题与页面复用规则。账户摘要复用 ConnectionText；连接状态独立观察授权、API、内容和真实任务结果。

按钮和配色使用完整的日夜角色，避免默认紫色混入。主动作实心、次动作文字、必要动作描边，新建为 16dp 圆角 Extended FAB；保留原生状态反馈、48dp 触摸目标、系统栏/键盘 insets 和 sp 文字。18 组静态文字/背景配对超过 4.5:1。

本轮六项文件菜单测试加既有测试合计每变体 201 项，另有 11 项独立检查、真实编译和 Lint。新版本没有连接设备供截图、触控、返回手势、字体缩放或 TalkBack 实测。仍需按 [验收清单](ACCEPTANCE.md) 检查；不以源码审查或编译代替手机体验，也不以网页假截图替代 Android。平板双栏和导航适配没有标记完成。
