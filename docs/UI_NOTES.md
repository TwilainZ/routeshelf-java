# 账号与 Drive 浏览界面说明

## 基础操作恢复补充

同一账号、文件夹、搜索和排序下刷新失败时保留最后成功的列表，错误旁提供重新加载/分页重试；切换上下文或账号立即清空旧列表。分页按 ID 去重并拒绝重复 token 循环。搜索支持清除按钮，系统返回先退出当前搜索。操作结果绑定账号会话，页面重建不会把写入失败悄悄变成成功提示。

云盘页直接显示传输状态、大小/百分比、取消和传输/已下载文件入口；失败或取消文字也保留。传输结束后刷新当前列表，避免上传成功后找不到新文件。此变更只有静态检查、编译和自动测试，尚无新设备截图或交互实测。


## 0.4.0 日常文件功能

常用文件库、共享云盘和快捷方式已接入；文件行复用原生 View，显示名称/摘要，主要操作与“更多”菜单并列，替代每行多个整宽按钮。菜单提供下载/导出、详情、复制链接、文件管理与共享。位置、排序、搜索和路径仅在同一会话的页面重建时恢复；进程重启或换账号不恢复旧会话路径。

管理操作在用户选择后单独说明并请求权限；界面显示只读/管理模式。新建和重命名输入、文件夹目标选择、星标、回收站及共享均接入 API。扩大链接访问、移除访问和永久删除有确认；永久删除还需要可靠版本条件。元数据写入由进程级协调器执行，页面旋转不重放请求。

上传用系统文件选择器，进度/取消复用传输页面。预览使用独立原生页面：PDF 翻页、图片、可选择文本和 SDK 音视频控件，后台暂停播放，退出清理缓存。超限/格式不支持/失效提供错误和重试。应用图标为本项目自绘文件夹与传输箭头，沿用蓝色主题。

这次仅有静态路径核对、真实编译和自动测试。没有已安装此版本的可用真机/模拟器，因此不声称视觉、布局、TalkBack、媒体解码、系统文件选择器、旋转或 Google 写入成功已通过；对应验收步骤见 ACCEPTANCE.md。

## 自动直连流程补充（0.3.0 开发预览）

下载页现在默认“自动直连”，与私人 Drive 浏览/下载共享设置；可显式切换“系统网络”。主流程不再要求寻找或输入 IP，也不再自动把扫描结果写入手工输入框。旧输入值不会恢复到新自动流程。手工覆盖公开下载 IP 放在可展开的高级设置中，收起会清空该值。

连接状态显示独立于文件下载进度，浏览页也能看到当前域名/地址、探测进度或失败；“重新检测直连”可取消。探测时禁止重复开始下载和改模式，下载中禁止手工重测/改模式。界面明确说明 Google 登录仍走系统网络，直连结果与当前网络有关。该补充依据源代码检查，没有新的设备截图、字体缩放或 TalkBack 验证；TLS/协议测试不能代替界面验收。

本文记录本次新增界面的实现与验证边界，不建立全应用设计规范。此前没有 `PRODUCT.md` / `DESIGN.md`；本次沿用既有蓝色下载页，没有替换视觉系统或整理未请求的样式差异。

## 范围与视觉角色

- `MainActivity` 保留原下载页的浅色背景、白色圆角卡片、蓝色主按钮及公开链接下载流程；新增“我的 Google Drive”入口，并调整公开下载、只读浏览及私人文件适用范围的文案。
- `DriveActivity` 使用原生 Android Views、AppCompat 与 `Theme.Material3.DayNight`，采用 Material 按钮、输入框和确认对话框。连接是实心主按钮，其余页面按钮为描边样式。
- 新页蓝色通过 Material 语义角色配置：日间 `primary` 为 `#315BD7`，夜间为 `#A9BDFF`；文字、背景及容器分别使用对应的 `onPrimary`、`surface`、`onSurface` 等角色。具体值以 `values/styles.xml`、`values-night/styles.xml` 为准。这不代表既有下载页已经完成深色模式改造。
- 新页沿用系统字体；正文、位置和文件名为 16sp，状态和文件详情为 14sp，控件采用 Material 默认排版。没有引入品牌字体，也未建立额外的全应用字号体系。

## 原生交互与布局

- 按钮和搜索输入设置至少 48dp 高度；搜索按钮与输入框间隔 8dp。实际触摸区域、文字放大后的可操作性仍需设备检查。
- 授权说明、连接操作、搜索、位置和状态位于 `ListView` 的可滚动头部，文件列表及“加载更多”尾部参与同一滚动范围，避免固定头部挤占小屏列表空间。
- 系统 Back 在子文件夹返回上一级，在根目录离开浏览页；操作栏提供返回下载页的入口。预测性返回手势体验尚未实测。
- 内容容器按系统栏、刘海和 IME 的实际 insets 加内边距；搜索支持键盘搜索动作并收起键盘。遮挡、焦点及键盘切换行为尚未实测。
- 文件夹位置标记为无障碍标题，状态采用 polite live region，文件操作的无障碍描述包含文件名；这些是代码中的支持措施，不等于 TalkBack 已通过验收。

## 已实现的界面状态

- **未连接与授权：** 说明只申请 Drive 只读权限，公开下载可继续使用；授权通过 Google 页面完成，进行中禁用重复连接，显示进度及状态文字。
- **取消、拒绝与错误：** 分别提示取消授权、缺少只读权限、授权失败及配置不匹配，并允许重试。没有把这些状态描述为已连接成功。
- **会话失效：** 会话失效或被清除时清空浏览内容并回到未连接状态；需要重新连接。实际 Google 账号的失效与重新授权尚未验证。
- **加载、空列表与分页：** 加载时显示进度并禁用相关操作；空列表提示清空搜索词重试；有下一页时显示“加载更多”。搜索仅作用于当前文件夹。
- **只读文件与下载：** 文件夹可进入；支持下载的文件提供“下载到设备”；不可下载或需要 Google 文档导出的项目显示原因并禁用下载，当前不支持文档导出。已有下载时避免重复启动，进度、取消及完成后打开文件仍在下载页。
- **本机断开：** 清除本机会话及列表，停止私人文件传输；文案区分本机断开与 Google 端撤销授权。
- **异步撤销：** 菜单先显示确认说明，保留已保存文件；撤销期间显示进度，并通过进程内共享门控禁用重新连接和重复撤销。页面重建后仍读取该门控，完成后恢复操作；撤销失败提示本机已断开，并提供重试或 Google 账号设置中的移除路径。
- **许可声明：** 菜单打开可滚动、可分页的原生许可对话框，并提供读取失败提示。

## 检查证据与限制

本次检查依据 `DriveActivity.java`、`MainActivity.java`、日夜主题及字符串资源。项目界面为原生 Android，没有 HTML/CSS detector 的运行结果。

独立 finish reviewer 最初发现“头部不可滚动”和“异步撤销与重新连接竞争”两项问题。修复后的静态复核仅将这两项标记为 **resolved / ship**；这不是全界面的视觉验收，也不能据此认定不存在其他问题。

API 35 软件模拟器在无 KVM 条件下冷启动，15 分钟内未完成应用安装，因此没有有效应用截图。尚未验证实际视觉、日夜主题呈现、字体缩放、旋转、IME、TalkBack、真实 Google 账号授权或私人文件下载。编译、单元测试与 CI 结果由对应工程报告单独记录，不能替代设备验证。

后续可在可用模拟器或设备上检查：日夜主题和 1.3 倍字体、小屏滚动和长文件名、旋转与键盘遮挡、系统 Back 和 TalkBack 顺序，以及授权取消、失效重连、空列表、分页、下载中断开、撤销期间重建页面和撤销失败后的恢复。
