# 0.6.0 UI 改进

主界面已按维护者指定改为接近 Google Drive 的 Material 文件浏览：默认进入云盘；顶部工具栏与固定搜索；底部首页（最近修改）、星标、共享、文件；右下角新建/上传。文件范围标题的下拉入口提供其他范围、回收站和共享云盘。文件行增加独立类型图标、大小和修改时间，保留两行文件名与更多菜单。公开链接下载/传输/连接设置在菜单中可达。

颜色调整为中性日夜表面和蓝色操作，系统无衬线字体。文件列表为浮动按钮保留滚动空间；控件至少 48dp、内容可增长；处理实际系统栏与键盘 insets。管理权限仍明确申请；下载不因单击不支持预览的文件而意外开始；危险操作继续确认。

本轮只有源码审查、真实编译、协议测试和 Lint，没有当前设备截图或 TalkBack 实测，不能说视觉已验收。此前无 KVM 模拟器启动失败，本次未重复。手机验收需覆盖 360dp/横屏、日夜主题、1.3/2 倍字体、键盘搜索与清除、文件菜单、返回/旋转、传输取消、网络恢复和只读管理授权。详见 DESIGN.md。

以下为 0.4.0 的历史审查记录，并非本轮截图证据。

# 历史：原生 UI 审查与修正

本轮针对公开下载页、云盘浏览、文件行、操作菜单和传输入口进行源码审查与修正。保留既有蓝色 Material 风格，优先让手机上的常用操作可发现、减少滚动和重复页面。没有可用真机或有效当前截图；此前无 KVM 的软件模拟器未完成安装，本轮没有重复该启动过程。以下不是视觉、手势、帧率或 TalkBack 实测结论。

## 审查结果

| 优先级 | 原问题及影响 | 本轮处理 |
|---|---|---|
| P1 | 开始下载在网络配置之后，用户要越过设置才能操作 | 按钮紧跟链接输入；进度随后显示，连接设置默认收起，仍可展开检查线路 |
| P1 | 云盘头部堆叠版本、IP、断开和排序，减少文件展示空间 | 版本留在诊断；线路设置和断开移入菜单；排序使用当前选项已勾选的菜单对话框 |
| P1 | 文件行有整行操作按钮，名称、详情和按钮纵向占高 | 点击名称区进入文件夹/预览，右侧 48dp 更多菜单；普通文件最小行高 72dp，长名称最多两行 |
| P1 | 下载页固定浅色和部分固定高度，字体放大和夜间使用不一致 | 接入同一 Material DayNight 主题、语义颜色和 Material 按钮；按钮高度随内容增长，保留最小触摸高度 |
| P1 | 原下载页依赖 fitsSystemWindows，未显式处理 IME 与显示切口 | 统一 edge-to-edge 和实际系统栏/切口/IME insets；方向改变正常重建并保存链接草稿/设置展开状态 |
| P2 | 表单错误只写在下方状态，键盘可能挡住提示 | 链接/IP 错误显示在对应输入；有效任务收起键盘并滚动至进度 |
| P2 | 上传藏在较后菜单，传输跳转可堆叠重复下载页 | 上传作为工具栏动作（空间不足保留在菜单）；传输与连接入口复用已存在的下载页并定位到对应内容 |
| P2 | 去掉文件行按钮后，点击二进制文件可能意外下载大文件 | 不能原生预览的文件先显示详情；下载/导出需明确选择，菜单也可直接发起 |

## 保留的设计与功能

- 文件列表使用原生 ListView 和 View 复用，头部/分页参与同一滚动区域；长文件名可通过详情查看，更多操作含文件名无障碍标签。
- 文件内容区、更多图标和按钮都有至少 48dp 的交互尺寸；图标为自绘 vector，不使用 Unicode 字符伪装图标。
- 搜索支持键盘提交和清除，系统返回与顶部返回先退出当前搜索；文件夹返回仍保留原路径行为。
- 刷新失败保留同一上下文的最后成功列表，并显示重试；分页去重及重复 token 保护继续生效。切换账号/目录/查询清除旧内容。
- 上传和下载保持前台进度、取消、失败提示及已保存文件入口。读屏不自动重复播报每次进度变化，完成/失败状态仍可提示。
- 管理权限仍明确选择后授权，权限扩大和永久删除仍需确认。UI 调整不改变认证、证书校验或传输实现。

## 验证边界与设备检查

真实 Gradle 编译、既有 79 项/变体 JVM 测试和 Android Lint 用于代码及回归验证，不能证明真实布局没有溢出。对主题 XML 中正文/次要文字对容器背景、主按钮文字对主色的六组组合做 WCAG 计算，最低为 5.82:1；这不包含所有控件状态或真实截图测量。

后续设备验收至少覆盖：360dp 手机和横屏/分屏；日夜主题；1.3 与 2 倍字体；键盘弹出后的错误提示和下载按钮；长中文/英文/RTL 文件名；TalkBack 名称区与更多菜单；系统返回；上传、取消、失败和恢复；连接/传输入口反复往返是否保持草稿和文件列表。平板与折叠屏仍是后续适配范围，不能宣称已经完整支持。
