# 产品范围

RouteShelf Java 面向 Android 上的 Google Drive 日常文件操作，包括浏览、预览、管理、传输及公开单文件下载。

Google 账号授权和数据连接是两条路径。授权使用平台支持的 OAuth 流程。数据连接可尝试经 TLS 验证的 Google 端点，第三方中转需要明确同意。账号可用、API 可达和文件传输成功分别显示。

应用使用 Material 3 和项目自有图标。操作反馈、错误恢复、日夜主题和无障碍优先。稳定的预览包名与签名用于现有用户升级。

项目由独立 Java 原型发展而来。可以参考公开功能、交互和协议，代码与资源的来源要求见 [许可证与归属](LICENSING.md)。
