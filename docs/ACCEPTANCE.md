# 0.7.2 客户端统一验收

本阶段已把日常客户端功能接入代码；“自动测试通过”不代表 Google 真实账号、所有 Android 设备或中国运营商网络已通过。开发期间不反复发中间包，不要求每次变更 Google 配置。

## 固定身份与一次配置

继续使用 `dev.gdirect.lite.preview` 和 `config/preview-signing.json` 中同一证书。0.7.2 是 versionCode 11，可更新此前同签名预览包；旧 `dev.gdirect.lite` 保留。维护者已报告完成现有预览客户端配置，更新无需新建客户端。新贡献者只有在自己的项目尚未配置时才参照 Google 配置文档。配置只读及管理范围后，在应用中按需要同意管理授权。功能更新不改变这个身份。

当前云环境没有已授权测试账号或可用真机；无 KVM 的软件模拟器此前未能完成启动和应用安装，不能替代账号、播放器、系统文件选择器及中国网络验收。此处是真实验收前的外部条件，不是要求把密码或令牌交给开发环境。

## 用一个专用测试目录完整走通

1. 以只读模式连接：浏览、搜索、分页、排序、共享云盘、快捷方式和文档导出。确认写入操作仍先询问管理授权，拒绝后仍可只读。断网刷新应保留同一目录已加载文件并提供重试；换账号/目录/搜索不显示旧列表，分页不重复，返回可退出搜索。
2. 启用管理，创建名为 `GDirect acceptance` 的新文件夹；上传内容已知的小文本、图片和超过 512 KiB 的二进制文件，核对 Google 中大小及 MD5。单次只传一个文件，同名上传会创建副本而非覆盖。
3. 上传期间切换网络并恢复、取消、关闭页面、旋转页面。查询服务器偏移后才能继续；失败后刷新核对结果，不能盲目重传。进程结束不承诺继续旧上传会话。
4. 在测试目录中重命名、星标、移动到子文件夹，再移动回来。旋转时不得重复创建或重复操作；另一账号重新连接后旧操作不得发往新账号。
5. 将测试文件移入回收站、恢复。永久删除仅对测试文件执行；缺少可靠 ETag 或文件版本已改变时必须拒绝，不强制删除。
6. 复制测试文件链接，确认权限未改变；使用不含私人内容的测试文件验收链接查看、查看权限和移除该权限。共享邀请仅发给维护者选择的测试账号，Google 会发送通知；不自动邀请任何人。
7. 预览 PDF 多页、常见图片、文本和设备支持的音视频；预览只使用私有缓存和本地组件。文本限 512 KiB，PDF/图片 64 MiB，媒体 256 MiB，Google 文档导出限 10 MiB；加密、格式不支持或超限时应提示下载，不能崩溃。
8. 私人下载核对大小/可用 MD5，公开下载测试强 ETag 续传和中断；断开后旧会话失效，已保存 Downloads 文件保留。单独验证当前会话授权撤销及 Google 账号设置中的移除。
9. 清除线路缓存，在没有历史成功地址的安装上取得 Google 官方 goog.json/cloud.json，验证非 Cloud 范围内的 DNS/历史过滤和 TCP 前端检测；默认仅 Google 模式下，列表不可达且没有有效缓存时，只验证内置公开报告中的有限范围，不自动回落第三方中转。检查设置中的候选/来源/日期，并确认失败候选不成为缓存路线。取得官方列表后检查移出范围/Cloud 内置候选被排除，取消不回退。额外验证允许中转的确认/取消、关闭后的缓存清除、状态归属，以及官方列表不可达时仅尝试已明确允许的固定候选。验证有效缓存可复用、更新失败不覆盖好数据。分别检查 Wi-Fi/移动网络、关闭代理/VPN 后的数据浏览和上传下载，并记录选中域名/IP/TLS 模式。账号登录仍由 Google 官方服务走系统网络。不能把本地回环 TLS 通过当成中国网络已可用。
10. 核对正常 SNI、无 SNI 和固定 g.cn 前端身份的状态；检查备用 IP/TLS 组合、GET 断线换线、私人文件内容跳转后不携带凭据，以及写操作不盲目重放。
11. 真机检查夜间主题、字体放大、键盘、返回、旋转、通知拒绝、磁盘不足、TalkBack；系统播放器/Provider 的兼容性以设备结果为准。

## UI 与图标验收

确认默认进入云盘、顶部搜索、底部首页/文件两个目标、新建/上传、范围选择和公开链接/传输菜单均可达。检查圆形、圆角方形启动器图标和 Android 13+ 主题图标；图形不能被裁切，深色主题文字和图标需清楚。没有本版截图前不得标记视觉通过。

## 尚未覆盖的能力

未实现传输队列、离线文件同步、跨进程上传恢复、协同文档编辑、挂载及任意自定义 SNI。没有自动覆盖同名上传、后台视频流式播放或关闭证书验证的降级。共享权限列表最多读取 2000 条，超限会提示在 Google Drive 管理。APK/单元测试不能证明这些未实现能力已经存在。

## 交付状态应如何记录

分别记录源码提交、APK 证书/校验值、Gradle/JVM/Lint/CI、设备安装和 Google 账号/网络结果。仅当相应检查真实完成才标记通过。隐私说明见“设置 → 关于与帮助 → 隐私与数据使用”；测试私钥保留在仓库外，CI Secret 和外部安全备份尚未落实，不能声称已经永久备份。

## 统一设置与连接恢复

检查“⋮ → 设置”四组条目、日夜主题、360dp/横屏/放大字体/TalkBack 和返回行为。检测中离开再进入、旋转、连续点击检测、取消并马上重试；应只有一个工作任务，取消完才可重启。检测期间切换模式不可用；完成后切换模式清除旧结果，不把旧端点显示为新模式已连接。传输期间禁用检测和模式切换，下载并行数只影响下一任务。中转选择取消后保持原模式。断开/撤销后账户状态与传输失效一致。隐私/许可在设置页查看，授权诊断从设置打开并保留原授权状态码。

## 冷连接回归（0.7.2）

分别在“仅 Google”和“自动连接 · 优先已知中转”下清线路/重启进程后加载目录。仅 Google 不能探测中转；同意中转后若它可用，应直接完成 TLS/服务验证，不先显示范围更新/DNS 阻塞。记录首次 API 成功和目录完成耗时、所选 IP/TLS；再测中转不可达时有界回退、取消、切网、热缓存目录重载。未提供当前设备对照前，不能把本地合成实验视作手机性能已恢复。

## 日志反馈验收（0.7.2）

在设置打开连接日志，清空后返回云盘执行一次慢连接，再刷新日志。核对中转/范围/DNS/扫描/HTTP/目录各阶段、耗时和原版本/构建；PROBE_HTTP 的 API 401 是正常匿名探测。检查复制、保存 TXT（取消/保存成功/Provider 拒绝）、选中长文本、旋转返回、大字体和夜间主题。等待约一秒后重启应保留记录；清空后重启不得恢复旧记录，之后新网络活动可以继续记录。进程突然终止可能丢最近一秒，不保证完整崩溃报告。磁盘不足时显示缓存不可用，当前内存日志仍能复制/保存。不要把账号、令牌、私人文件名/ID/URL、资源密钥、Cookie、搜索词和响应正文加入导出；真机文件提供器与剪贴板流程仍需设备验收。


## 连接状态页（0.7.5）

- 账户已授权但断网时，主界面与状态页显示设备离线，不显示数据连接成功。
- 从主界面入口和设置进入同一状态页；打开页面不重复扫描，正在检测时旋转/返回再打开保留进度与耗时。
- API 无凭据 401 标为线路验证；文件根路径响应不标为下载成功。实际下载完成后才更新下载证据。
- API 403/404 显示访问/权限问题，正文断流显示连接失败，停止/切换 VPN 后清除旧状态并展示当前 VPN 提示。
- 等待五分钟后不继续显示新鲜验证；系统模式能检测，传输中禁止清线重检，取消未结束时不能重启。
- 在 360dp、横屏、夜间和大字体下检查按钮、错误换行、滚动、返回和 TalkBack。此处为设备待验收项目。

## 目录刷新回归（0.8.1）

加载一个目录后停留至少 30 秒：列表保持可操作，日志不应继续连续出现 LIST_BEGIN。分别主动刷新、再次点击当前底部标签、切换四个标签、搜索、排序和分页，确认只产生预期请求；旋转后不循环加载。取消读取、切网和账户失效不应淘汰健康线路，实际超时/断流仍可换线。大文件下载、导出和上传不套用元数据 12 秒整体时限。JVM 测试模拟导航回调并使用真实回环 TLS；Material 控件和运营商行为仍需在手机检查。

## 传输入口回归（0.8.2）

从浏览页“查看传输”、工具栏传输菜单及前台通知分别打开：应直接看到独立传输详情，不展示链接输入框，不弹键盘。下载完成直接打开文件，上传完成不展示本地打开按钮；进行中可停止，失败/停止不显示下载等待或完成。空状态不显示伪造的历史/进度。公开链接下载仍可从菜单单独进入，粘贴和验证保持，开始后进入详情；返回保留输入。旋转、日夜主题、横屏、360dp、大字体和 TalkBack 检查状态及操作不被遮挡。底部只出现首页/文件，切换与再次点击不触发循环刷新。

## Material 配色与按钮（0.8.3）

日夜主题分别检查：首页/文件的选中态为蓝系，搜索/导航使用中性表面，不混入默认紫色；新建为浅蓝 16dp 圆角，主动作实心，查看传输/分页/重试为文字按钮，停止保留清楚的次级层级。检查按下、禁用、焦点与波纹反馈，48dp 触摸目标和大字体下的内容宽按钮换行。静态对比度已检查；实际设备颜色和 TalkBack 仍需验收。
